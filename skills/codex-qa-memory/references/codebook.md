# 数字码表

数字码是查询维度，不是永久主键，也不是深层目录路径。永久主键使用 `EC-*`、`N-*`、`R-*`。

## v2 解码规则

- 数字码和 0/1 标志给 CLI/工具计算、过滤和排序使用。
- LLM 短包和最终输出必须同时带短中文解码，例如 `status_code=302（active，当前有效）`。
- 禁止把纯 `202 302 400 1 0` 这类裸串作为 LLM 主输入、记忆正文或用户可见结论。
- 0/1 标志必须配中文标签：`cross_project_allowed=0（禁止跨项目触发）`、`temporary_authorization=1（临时授权）`、`runtime_state=1（运行态状态）`。
- 跨项目默认允许的内容只限用户长期习惯、全局偏好、全局红线和通用执行策略；项目状态、临时授权和运行态状态不得跨项目默认触发。

## 9xx 扩展码

`9xx` 仅用于实验、临时兼容或外部系统映射。正式进入 active 前必须写清来源、兼容关系和废弃策略。
