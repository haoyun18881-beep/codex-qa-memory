# Security Policy

## Private Data

Do not publish real Codex sessions, QA diaries, memory records, vector indexes, watcher logs, manifests, tokens, cookies, API keys, account exports, or private project files.

This repository contains source code, skills, templates, and sanitized examples only.

## Redaction

The logger includes basic redaction for common secret shapes, but it is not a legal or security guarantee. Review generated diaries before sharing them.

## Reporting

Open a GitHub issue for non-sensitive bugs. For sensitive issues, contact the maintainer without including secret values.
