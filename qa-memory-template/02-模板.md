# QA 记忆模板

## 事件卡

```yaml
event_id: EC-YYYYMMDD-001
title: 简短标题
time: YYYY-MM-DD
scope_code: 408
scope: global.codex.qa
summary: 200 字以内说明这件事、结论和为什么重要。
source_ref: path-or-history-id
status_code: 300
nodes:
  - N-YYYYMMDD-001
gate_result: candidate
sensitive: none
created_at: YYYY-MM-DD
updated_at: YYYY-MM-DD
```

## 小节点

```yaml
node_id: N-YYYYMMDD-001
type_code: 202
status_code: 300
scope_code: 408
content: 一句话，只表达一个事实、偏好、规则、决策或状态。
source_ref: path-or-history-id
event_id: EC-YYYYMMDD-001
created_at: YYYY-MM-DD
updated_at: YYYY-MM-DD
confidence: medium
tags: [标签]
sensitive: none
```

## 关系边

```yaml
edge_id: R-YYYYMMDD-001
from: N-YYYYMMDD-001
to: EC-YYYYMMDD-001
rel_code: 105
status_code: 310
source_ref: path-or-history-id
created_at: YYYY-MM-DD
sensitive: none
```

## QA 取回包

```text
QA取回包:

项目/工具边界:
下一步:

```

## 超过 3 个节点时的理由

```text
超过原因:
影响范围:
为什么不能合并成事件卡摘要:
哪些节点需要人工复核:
```

## Gate

| Gate | 通过条件 | 失败时动作 |
| --- | --- | --- |
| 低成本 Gate | 每轮默认 0-3 个小节点 | 超过必须写理由 |
| 单义 Gate | 一个节点只表达一件事 | 拆分或回到事件卡 |
| 来源 Gate | 有 `source_ref` | 无来源不得 active |
| 状态 Gate | 有 `status_code` | 无状态不参与默认取回 |
| 数字码 Gate | 码只做字段和查询条件 | 禁止深层数字路径 |
| 敏感 Gate | 不含凭据原文 | 隔离或只记录类别 |
| 提升 Gate | 高影响项人工复核 | 标 `review_required` |
